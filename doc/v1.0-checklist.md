# v1.0 검증 체크리스트

다음은 `final-design.md` 기준에 따른 빠른 검증 항목과 현재 상태(초기 검사 기준)입니다. 로컬/배포 환경에서 수동으로 검증한 후 상태를 `Implemented`/`Needs review`/`Fix required`로 갱신하세요.

- **HTML 시맨틱 구조**: Implemented — `header`, `nav`, `main`, `section`, `footer` 존재
- **CSS 변수 / Light & Dark**: Implemented — `css/style.css`에 변수 정의 및 `[data-theme]` 사용
- **Theme 저장/복원**: Implemented — `localStorage` 사용, `initTheme()`에서 복원
- **스크롤 기준 (Header)**: Implemented — 코드값 `50` (README에 기록)
- **Scroll-to-Top 기준**: Implemented — 코드값 `300` (README에 기록)
- **IntersectionObserver**: Implemented — threshold `0.2`
- **Projects (GitHub API 호출)**: Implemented — `fetch` + error handling 존재. 사용자: `yerihanview`
- **Projects 상태 UI**: Implemented — loading / success / error / empty 상태 처리
- **Project cards (동적 렌더링)**: Implemented — `createProjectCard`로 동적 생성, Grid 스타일 확인 필요
- **Filter 동작 (client-side)**: Implemented — `originalRepos`를 유지해 재요청 없음. DevTools에서 네트워크 확인 필요
- **Contact Form validation**: Implemented — 이름/이메일/메시지 검증 및 상태 UI
- **Accessibility**: Partial — `label`/`for` 연결 존재, 추가 aria 체크 권장
- **Responsive (mobile/tablet/desktop)**: Needs review — 레이아웃 테스트 필요 (브라우저 devtools)
- **이미지 경로**: Implemented — `images/profile.svg` 존재; GitHub Pages에서 로드 확인 필요
- **No external frameworks**: Implemented — React/Vue/jQuery/Bootstrap/Tailwind 없음
- **Console errors**: Needs review — 브라우저에서 확인 필요

검증 절차(권장)
1. 로컬 서버 실행: `python3 -m http.server 8000`
2. 브라우저에서 각 섹션(모바일/태블릿/데스크톱) 확인
3. DevTools → Network로 Projects 필터 클릭 시 추가 API 호출이 발생하지 않는지 확인
4. Projects 상태 전환(loading → success / error → retry) 흐름 확인
5. GitHub Pages에 배포 후 이미지/경로 이슈 확인
